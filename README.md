# Heyll 个人主页

一个纯静态的个人主页 / 引导页，原生 HTML + CSS + JS 实现，无框架、无构建步骤。

---

## ✨ 特色

- **白天 / 黑夜模式**切换
- **5 套白天主题**，通过 CSS 变量控制，无 JS 依赖
- 支持**背景整体模糊**与**卡片模糊**，可通过 CSS 切换
- 加载动画、点击气泡动效
- 响应式布局：桌面端一行 4 个项目，移动端支持一行两个 / 一行一个
- 侧边栏支持移动端弹出
- 页面图标全部为 SVG 字体图标，路径均为相对路径
- 使用**原生 HTML、CSS、JS**，未使用框架或插件

---

## 💻 使用

下载并解压后直接用浏览器打开 `index.html` 即可，主要文件：

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与内容 |
| `static/css/root.css` | 主题样式（主题变量） |
| `static/css/style.css` | 主样式，可修改字体 |
| `static/js/script.js` | JS 功能 |
| `static/img/favicon.ico` | 网页图标与头像 |

### Docker 部署

自行安装 `docker` 与 `docker-compose`，修改 `Caddyfile` 中的域名后运行：

```bash
docker compose up -d
```

会自动申请 SSL 证书并开启 HTTPS。
